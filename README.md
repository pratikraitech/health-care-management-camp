# CareCamp — Community Health Camp Platform

A responsive, multi-page front-end prototype based on the supplied project brief.

## Pages
- `index.html` — Homepage and navigation hub
- `camps.html` — Camp listings with search and category filter
- `register.html` — Participant registration form with browser-local demo storage
- `appointments.html` — Appointment slot selection
- `dashboard.html` — Organizer dashboard with sample metrics and quick links
- `reports.html` — Sample participation and attendance reports, with print option
- `privacy.html` — Privacy controls and implementation guidance

## Run
Open `index.html` in a browser. No build step is required.

## Important
This is a static demo. It does not include a backend, real authentication, real appointment inventory, SMS/email reminders, or production-grade privacy/security. Registration data is stored only in the current browser's localStorage. All camp details and dashboard figures are fictional sample data. Do not enter real patient or sensitive health information.

For production, connect a secure backend/database, authenticated organizer accounts, role-based access control, verified camp data, reminder service, audit logging, consent workflows, and appropriate privacy/security compliance.
